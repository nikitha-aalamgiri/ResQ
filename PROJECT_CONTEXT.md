ResQ is an operational Flood Emergency Response and Coordination Platform providing rapid incident routing, life-safety dispatch, and live situational awareness during urban flooding events.
The system is built on a full-stack monorepo featuring a Vite + React + Tailwind CSS frontend, an Express (ES modules) backend service, and Supabase PostgreSQL with Row Level Security (RLS) and Realtime WebSocket subscriptions.
The platform supports three distinct operational roles: Citizens (submitting SOS distress requests and checking shelter availability), Responders (triaging open incidents, accepting field assignments, and reporting road status), and Admins (command-center coordination, agency management, and system-wide broadcast alerts).
The core demo loop demonstrates a citizen dispatching an emergency SOS (incident ID format FQ1024) in Hyderabad, instant Realtime broadcast to responders and command staff, assignment to field teams, and automated map synchronization of active flood zones, blocked roads, and shelter capacities.
